# C++ Problem Set: Linked List + Class

## 🟢 Problem 1: Student Record Manager [EASY]

### Statement

Ek college ko students ke records dynamically store karne hain. Har student ke paas:

* Roll Number
* Name
* Marks
* Next student ka pointer

`Student` ko class ke form mein design karo aur **singly linked list** use karke students ko store karo.

Implement:

1. Student add at beginning
2. Student display
3. Total students count

### Input

* Number of operations `Q`
* `1 ≤ Q ≤ 10^4`
* Roll number: positive integer
* Marks: `0–100`

Operations:

```text
ADD roll name marks
DISPLAY
COUNT
```

### Output

Operations ke according student records display karo.

### Example

**Input**

```text
ADD 101 Rahul 78
ADD 102 Aman 85
DISPLAY
COUNT
```

**Output**

```text
102 Aman 85
101 Rahul 78
2
```

**Explanation:**
Beginning mein insertion ki wajah se `102` head ban gaya.

### Edge Cases

* Empty list
* Sirf ek student
* Multiple students
* Duplicate roll number

### Hints

* `Student` class ke andar `Student* next` rakho.
* `head` ko separately maintain karo.
* New object dynamically create karo.
* Beginning insertion mein `newNode->next` ko current head se connect karo.

### Expected Time Complexity

* Insert: `O(1)`
* Display: `O(N)`
* Count: `O(N)` if count variable maintain nahi kar rahe

# 🟢 Problem 2: Employee Management System [EASY]

### Statement

Ek company employees ko linked list mein maintain karti hai.

Har employee ke paas:

* Employee ID
* Name
* Salary
* Next pointer

Class ke member functions se implement karo:

* Insert at end
* Display employees
* Find employee by ID

### Input

```text
ADD id name salary
SEARCH id
DISPLAY
```

Constraints:

* `1 ≤ N ≤ 10^5`
* Salary `> 0`

### Example

```text
ADD 101 Raj 30000
ADD 102 Amit 45000
SEARCH 102
```

Output:

```text
Employee Found
102 Amit 45000
```

### Edge Cases

* Search empty list
* ID doesn't exist
* Search first node
* Search last node

### Hints

* End insertion ke liye `temp` pointer use karo.
* Search ke liye head se traverse karo.
* Data ko class members mein encapsulate karo.

### Expected Time Complexity

* Insert end: `O(N)`
* Search: `O(N)`

# 🟡 Problem 3: Bank Transaction Linked List [MEDIUM]

### Statement

Ek bank account ki transactions linked list mein stored hain.

Har transaction object mein:

* Transaction ID
* Amount
* Type: `Deposit` / `Withdraw`
* Next pointer

Implement:

1. Add transaction
2. Display transactions
3. Calculate current balance
4. Find largest transaction

### Input

```text
DEPOSIT 101 5000
WITHDRAW 102 1500
DEPOSIT 103 3000
BALANCE
MAX
```

### Example

```text
DEPOSIT 101 5000
WITHDRAW 102 1500
DEPOSIT 103 3000
BALANCE
```

Output:

```text
Balance: 6500
```

### Edge Cases

* No transactions
* Only deposits
* Only withdrawals

# 🔴 Problem 6: Linked List Using Separate List Class [HARD]

### Statement

Ab architecture improve karo.

Do classes banao conceptually:

### `Node`

Student ka data + `next`

### `LinkedList`

List ko manage kare:

* `insertBeginning()`
* `insertEnd()`
* `deleteValue()`
* `search()`
* `display()`
* `size()`

User ko directly node pointers manipulate nahi karne chahiye.

### Example

```text
LinkedList list;

list.insertEnd(10);
list.insertEnd(20);
list.insertBeginning(5);
list.deleteValue(20);
list.display();
```

Expected:

```text
5 10
```

### Edge Cases

* `head == nullptr`
* One-node list
* Delete head
* Delete last
* Delete nonexistent value
* Repeated values

### Hints

Ye question **encapsulation** test karega.

User-facing code ko linked-list ke internal pointers se separate rakho.

### Expected Time Complexity

* Beginning insertion: `O(1)`
* End insertion: `O(N)`
* Search: `O(N)`
* Delete: `O(N)`

# 🔴 Problem 7: Reverse Linked List Using Class [HARD]

### Statement

Employee records ko linked list mein store kiya gaya hai.

List ko **in-place reverse** karo.

Original:

```text
101 → 102 → 103 → 104 → NULL
```

After reverse:

```text
104 → 103 → 102 → 101 → NULL
```

### Important Requirement

❌ New linked list mat banao.
❌ New nodes mat create karo.

Existing nodes ke pointers modify karo.

### Edge Cases

* Empty list
* One node
* Two nodes
* Large list

### Hints

Three pointers ke baare mein socho:

```text
previous
current
next
```

Har iteration mein current node ka `next` reverse karna hai.

### Expected Time Complexity

`O(N)`

### Extra Space

`O(1)`

# 🟣 Problem 9: LRU Cache Using Classes [DIFFICULT]

### Statement

Ek browser ke paas limited cache capacity hai.

Recently accessed pages ko cache mein rakha jata hai.

Example:

```text
Capacity = 3

A
B
C
GET A
PUT D
```

`A` recently accessed tha, isliye least recently used page `B` remove hoga.

Final:

```text
D → A → C
```

### Requirement

Use:

* `Node` class
* Doubly linked list
* Hash map

### Edge Cases

* Capacity `1`
* GET nonexistent key
* Repeated GET
* PUT existing key
* Empty cache
* Eviction

### Hints

Sirf linked list se `GET` efficient nahi hoga.

Think:

```text
HashMap
   ↓
Node*
   ↓
Doubly Linked List
```

Hash map node ka address store kar sakta hai.

### Expected Time Complexity

Average:

* `GET`: `O(1)`
* `PUT`: `O(1)`

## **Problem 1: Student Roll Call**

A school maintains a student attendance list. Each student has a roll number and name. When a student is present, they're added to the list. Print all students in the list.

**Problem:** Create an SLL and traverse to print all nodes.

**Input:**
```
Roll: 1, Name: "Raj"
Roll: 2, Name: "Priya"
Roll: 3, Name: "Amit"
```

**Expected Output:**
```
1 -> Raj
2 -> Priya
3 -> Amit
```

---

## **Problem 2: Bus Queue**

Passengers are waiting in a queue for the bus. When a new passenger arrives, they join at the end. When the bus leaves, passengers board from the front one by one.

**Problem:** Simulate a queue - add passengers and remove them in order.

**Input:**
```
Add: "Person1"
Add: "Person2"
Add: "Person3"
Remove (first person boards)
Add: "Person4"
Print all waiting
```

**Expected Output:**
```
Removed: Person1
Waiting passengers:
Person2 -> Person3 -> Person4
```

---

## **Problem 3: Print List in Reverse**

You have a linked list of items. Print the list in reverse order (without actually reversing it).

**Problem:** Traverse and print the linked list in reverse order using recursion or stack.

**Input:**
```
List: 10 -> 20 -> 30 -> 40 -> None
```

**Expected Output:**
```
40
30
20
10
```

---

## **Problem 4: Remove Duplicate Elements**

The student roll number list has duplicate entries. Remove all duplicates, keeping only the first occurrence.

**Problem:** Delete duplicate nodes from SLL.

**Input:**
```
1 -> 2 -> 2 -> 3 -> 3 -> 3 -> 4 -> None
```

**Expected Output:**
```
1 -> 2 -> 3 -> 4 -> None
```

---

## **Problem 5: Find Middle Element**

A music playlist has several songs. Find the middle song in the playlist.

**Problem:** Find the middle node of the linked list.

**Input:**
```
Songs: "Song1" -> "Song2" -> "Song3" -> "Song4" -> "Song5" -> None
```

**Expected Output:**
```
Middle song: Song3
```

---

## **Problem 6: Delete Nth Node from End**

You have a list of comments. Delete the Nth comment from the end.

**Problem:** Delete the Nth node from the end of the list.

**Input:**
```
List: 1 -> 2 -> 3 -> 4 -> 5 -> None
N = 2 (delete second from end, which is 4)
```

**Expected Output:**
```
1 -> 2 -> 3 -> 5 -> None
```
